# Victoria Cuccina Landing Page

## Website Flow

1. **Home Page** - Landing page with restaurant information and navigation menu
2. **Menu** - Display of food items and offerings
3. **About Us** - Restaurant details and description
4. **Contact** - Contact information and inquiry form
5. **Gallery** - Images of food and restaurant ambiance

## Features

- Responsive design for mobile and desktop
- Interactive menu display
- Contact form for customer inquiries

## Reservation System

**Note:** The optional `mail.php` file for reservation functionality has been removed from this project. If you need email-based reservations, you'll need to implement an alternative backend solution.
